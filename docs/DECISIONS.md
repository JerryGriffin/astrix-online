# Astrix 设计决策记录（截至 v0.2.2）

> 记录每一版**已确认**的设计决策与**仍待定**的问题。已确认项若你要改，一句话我就同步全表。

## 一、技术栈与发布（长期有效）

| 项 | 决策 |
|---|---|
| 发布方式 | 平台托管为静态站点，**每次改完直接自动发布** |
| 在线模式 | 内置云服务（云端数据库 + 账号体系，真多账号、真同步）；当前为占位 |
| 技术栈 | 原生 HTML/CSS/JS，**零构建、零依赖**，单页应用 |
| 材料数值 | 混合：密度 / 熔点 / 比热容用真实物理数据，强度 / 耐久 / 特殊能力按游戏平衡自定 |
| 主题 | 深空暗色 + 冷色高亮（青为主色，橙为强调色） |
| 响应式 | PC 与移动端两套布局，走 CSS 媒体查询，不用 JS 判 UA |
| 版本号 | **单一来源** `js/version.js`（`VERSION` / `VERSIONS`），入口脚本带 `?v=` 击穿缓存 |

## 二、已确认决策

### 计量与格式（v0.0.1）

| 项 | 决策 |
|---|---|
| 计数单位 | k=10³、m=10⁶、g=10⁹、t=10¹²，超过 t 用科学记数法（如 1.5e15） |
| 时间格式 | 秒为主 + 自动进位：`12s` → `5min` → `3h` → `2d` |
| 星球编号 | `<星球名前三个字母小写><序号>`，如 syl1、syl2、des1 |
| 星球距离 | 每星球分配轨道半径与公转相位，距离取实时直线距离 |

### 材料与资源（v0.0.2 / v0.0.3）

| 项 | 决策 |
|---|---|
| 金属呈现 | 星球上能挖到的**一律是矿石**（赤铁矿 / 孔雀石 / 闪锌矿 / 铝土矿 / 金红石 / 粗银 / 粗金 / 黑钨矿 / 锂辉石 / 软锰矿 / 沥青铀矿 / 铱铂矿），纯金属一律是 `refined` 精炼产物 |
| 钛 | 以原矿**金红石 Rutile**（TiO₂）呈现，纯钛为精炼产物（`refinedFrom: '金红石'`） |
| 「镒」 | **虚构元素 Eridium**（符号 `Ed`，因为 Er 已被铒占用），顶级稀有 + **高级货币**，不映射到任何现实元素 |
| 铱 | 真实元素 Ir 保留，原矿为**铱铂矿 Osmiridium** |
| 化合物 | **排除**。不收录肼 / 联氨、硅橡胶等化合物；但**燃料栏**里保留联氨（作为燃料） |
| 树脂 / 有机物 | 两个词条**合并为「有机质」** |
| 气体 | 氨（氨气）**只以气态存在**，不在地表 / 地下 / 地核刷新，只能靠大气收集器取 |

### 货币（v0.0.2）

| 项 | 决策 |
|---|---|
| 星际通用货币 | **Ascoin** |
| Ascoin ↔ 金 | **1048576 Ascoin 恒等于 1 金**（1048576 = 2²⁰） |
| 镒（Eridium） | **稀有货币，无固定汇率、不可与 Ascoin / 金兑换**，只单独计数 |
| 玩家的「金」 | 就是物品栏里的金材料；Ascoin 是独立计数项 |

### 燃料（v0.0.2）

| 项 | 决策 |
|---|---|
| 热值刻度 | 按**物质的量**计，游戏热值 = 真实 kJ/mol ÷ 100 |
| 燃烧速率刻度 | 以**甲烷 = 1.0** 为锚的相对 mol/s；1 燃烧强度下烧完时间 = 1 / 速率 |
| 核燃料 | 铀 / 钚按**真实摩尔裂变能**折算进同一刻度、不封顶；定位为**终局慢速燃料** |
| 热值排序 | 钚(2.03e8) > 铀(1.93e8) ≫ 甲烷(8.9) > 联氨(6.2) > 碳(3.9) > 标准煤(3.5) > 氢气(2.9) |

### 人力与幸福度（v0.0.2 / v0.0.4）

| 项 | 决策 |
|---|---|
| 营养消耗基数 | 1 人力 / 秒消耗 **0.01 氧气 + 0.01 有机质**（「休息」态）；开荒给 1e5 氧气 + 1e5 有机质（≈2.8 小时口粮）形成前期压力 |
| 工作强度 | 5 档：休息 ×1.0 / 轻度 ×1.5 / 标准 ×2.0 / 高强度 ×3.0 / 极限 ×4.5（消耗倍率）；产出倍率 0 / 0.5 / 1.0 / 1.5 / 2.0 |
| 一人一事 | 1 个人力同时只能干一件事，**手动分配**；没人工作的资源产出恒为 0 |
| 三个数字 | **总人数** / **总人力**（= 总人数 × 0.9）/ **可用人力**（= 总人力 × 幸福度 − 已分配） |
| 开局 | 希尔瓦 总人力 1000 / 可用 900（幸福度 0.9）；其余 6 星 0 人，需从希尔瓦移民 |
| **幸福度公式（v0.0.4 定稿）** | `H = 0.40 + 0.35·S − 0.30·(1−S) + 0.15·C − 0.50·clamp((W−0.60)/0.40) − 0.40·min(1, |T−293|/40)`，夹取到 [0,1]。<br>S = 供给/需求，C = 庇护覆盖率，W = 已分配/总人力，T = 环境温度 K |
| 公式自校验 | 吃饱 + 有庇护 + 20 ℃ + 不过劳 → **0.90**，正好对上希尔瓦的 1000/900 |
| 人口变化 | 幸福度 > 0.5 增长、< 0.3 下降，否则持平 |

### 建筑与科技（v0.0.3 / v0.0.4）

| 项 | 决策 |
|---|---|
| 建材 | 一律用**精炼金属与复合材料**，不用原矿；早中期几座受「建材可获得性铁律」限制只能用露天材料 |
| 建材可获得性铁律 | 建筑只能用「解锁它的科技层级或更低」的材料（详见 `docs/buildings.md` 第〇节） |
| 岗位数 | 全部建筑岗位 ×4，共 **616 个工位**（21 座建筑） |
| 默认解锁 | **科研所** 与 **建筑工厂** 不需要科技，开局可建（否则研究点 / 施工死锁） |
| **施工硬门槛（v0.0.4）** | 必须**有人在「建筑工厂」当建筑工**才会开工；没人则施工速度**恒为 0**。这是「没它就不能建」，不是「加快建造」 |
| 人力发电厂 | **无前置**，开局唯一电源；**只靠人力，不消耗木头、不消耗任何燃料** |
| 熔炉耗电 | **0**（燃烧有机质自身放热，自供能），切断「熔炉↔人力发电厂」死锁 |
| 船坞定位 | **不是终点**：只前置 C2 深层矿井；是 A3 生物工厂 / B3 电解池 / D1 化学实验室 / C3 地心矿井的前置，并开启舰船支线 |
| 农田 | A2 解锁，消耗二氧化碳产出有机质 |
| 自定义化工厂 | D3 解锁（极高科技，前置 D2），可自定义配方 |
| 制造车间（v0.0.4） | E4 解锁，前置 E2 修理厂，生产小型与中型物品 |
| 大气收集器（v0.0.4） | A4，前置 **A1 + B2** |
| 精细加工厂 | 2 个相同材料 → 1 个，属性与精细度每次 +1；代价是以该材料建造的建筑**修理时间增加** |
| 科技层级 | 由前置关系**自动算出**（`computeTiers`），改前置时 UI 排版自动跟随 |
| 研究点花费 | 仅 A1(500) / A2(300) / A3(10e5) / D3(10e5) 为设计者给定，其余为按层级推算的**占位值** |
| 科研面板（v0.0.4） | 分**三大方向**：科技 / 升级 / 设施。船上设施从科技树移入「设施」子分类 |

### 舰船（v0.0.4）

| 项 | 决策 |
|---|---|
| 四大支线 | 舰船外壳（超小型/小型/中型/大型/超大型）、引擎（基础引擎 + 轻型/均衡/重型/超重型）、武器（机枪/舰炮/火箭/激光器）、船上设施（乘员仓/仓库/机库/装甲） |
| 型号阶梯 | 各支线 MKI → MKII → MKIII，由 `t_ship_mk2` / `t_ship_mk3` 两个节点统一开关 |
| 蓝图合法性 | 容量 ≥ 总占地、部件数 ≤ 槽位、**必须有乘员仓**、所有部件科技已研究 |
| 航速 | `速度 = 300 × 总推力 / 总质量^0.7` |
| 起飞燃料 | `能量 = 0.5·m·Δv²/效率`，`摩尔数 = 能量/(游戏热值 × 1e5)`；Δv 随星球重力放大 |
| 材料影响 | 外壳吃强度/密度/熔点；引擎推力吃 √强度；武器伤害吃强度；装甲吃强度；全部质量吃密度 |
| 耐热上限 | 全船取各部件最低值（最弱环节决定上限） |
| 温度致死 | 安全区间 273–313 K、致死区间 253–333 K，乘员仓每级两端各放宽 4 K；船员归零变幽灵船 |
| 自动命名 | `<型号>级<类型>No.<同型序号>`，如 **MKI级运输船No.1**；玩家可改名 |

### 人力与营养（v0.0.5）

| 项 | 决策 |
|---|---|
| 休息代谢（一吃五出） | 每人每秒消耗 **氧气 0.01 · 有机质 0.01 · 水 0.01**，产出 **二氧化碳 0.01 · 甲烷 5e-4 · 氨气 5e-4**；工作强度在基数上同时放大消耗与产出 |
| 岗位可见性 | **只显示能分配的岗位**：需建筑的岗位在建筑建成前一律不渲染（未解锁同理），底部一行告知隐藏了多少个 |
| 建筑工位池 | 空闲工位 = **建筑数 × 每座工位数 − 该建筑下已指派人数**；一座建筑下的多个职业（如制造车间的小型/中型物件工）**共用一个工位池** |
| 分配方式 | 每行 −/数字输入栏/＋/满员 —— 输入栏支持一次填几百人，避免大规划时点几百次 |
| 双重夹取 | 一次分配同时受「可用人力」与「建筑空闲工位」夹取，取小者 |

### 房屋与庇护（v0.0.51）

| 项 | 决策 |
|---|---|
| 房屋 | 新增建筑，造价 **泥土 200 + 石头 100**（全 T0，默认解锁不会死锁）、`growth` 1.10（全表最低）、工作量 200、**不提供工位** |
| 庇护 | 每栋 **100 点**；总庇护 = Σ(座数 × shelter)；庇护率 `C = 总庇护 / 总人数`，夹取 [0,1] |
| 开局 | **5 座房屋 = 500 庇护**，希尔瓦 1000 人时 C = 0.5 → 幸福度 0.825（而非满值的 0.90） |
| 接线 | `advancePopulation()` 现在把 `shelter: shelterRatio(inst)` 传进 `tickPopulation`；此前庇护项恒为 1，房屋无效 |
| 人口速率 | 调慢约 100 倍：挂机 1 小时 **+9.0%**（旧值相当于 1 小时 1339 倍） |

### 线上部署与同步链路（v0.2.2-rev15）

| 项 | 决策 |
|---|---|
| 公网发布链路 | GitHub `JerryGriffin/astrix-online` push → `.github/workflows/sync_to_hf.yml` → HuggingFace Space `Recapiut/astrix-online` |
| Space SDK | **`sdk: static`**。2026-09-30 曾试探性改为 `docker` + `app_port: 7860` 以恢复公网真联机，**被账户配额硬阻断**（见下一行），已回滚 |
| 免费账号的硬门槛（决定性） | HuggingFace **免费账号无法运行 Gradio / Docker Space**，只能托管 Static Space；运行计算型 Space 需付费 PRO。实测：改为 `docker` 后 Space 报 `Quota exceeded for flavor cpu-basic (requested=1): current=0, limit=0`、进入 `PAUSED`、整站 503。官方工作人员原话：「Creating a Space that runs on compute (Gradio or Docker) requires a paid plan. **This includes converting an existing Static Space to Gradio or Docker.**」⇒ **HF 免费额度下公网真联机不可落地** |
| 公网真联机的现实路径 | 把整个项目（静态资源 + `server.mjs`）部署到任一能跑 **Node 单端口 HTTP 服务**的主机：`server.mjs` 同源托管全部内容，**前端零改动**，`/api/online/*` 相对路径直接成立。HF 只继续承担静态站点托管（单机 + NPC 可玩） |
| 全服状态持久化 | `server.mjs` 内置三层后端：`hf`（提交快照到私有 Dataset 仓库）/ `file`（本地 `data/online-state.json`，默认）/ `memory`。免费层容器磁盘**重启即丢**（HF 官方文档），故跨重建恢复必须走外部快照。配置与验证见 `docs/HF_STATE_PERSISTENCE.md`；往返自检 `docs/selfcheck_online_state.mjs`（36 项） |
| 同步链路保护 | `.gitignore` **不得**写成 `.github/`——那会把 `sync_to_hf.yml` 一并忽略，同步会**静默失效**；正确写法是 `.github/*` + `!.github/workflows/`（rev15 已修正） |
