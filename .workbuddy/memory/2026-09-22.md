## v0.1.3 修订2：离线结算三处真 bug（CACHE_TAG 13.2，版本不变）
1. **内存没换成推进过的实例**：settleOffline 只把结果写盘，最后又 `STATE.planets = prevPlanets` 恢复旧数组 → UI 读到「离线前」状态（玩家看到根本没推进），且下一个心跳 saveState 把旧状态写回磁盘，**离线成果被覆盖**。修：记录 `settledPlanetsOfCurrent`，结束时用它恢复。
2. **裸实例跑 tick（离线上产线恒 0 的根因）**：`loadPlanets()` 反序列化出的实例没走 `getPlanetInstance` 的运行时初始化（补 pop/energy/atmosphere/ensureLines/注入 `_gasAvailable`）→ `inst.pop` 为 null → `intensityMulOf` 取 0 → 生产线一点不产出。修：结算前对每个实例调一次 `getPlanetInstance(p.code)` 补运行时字段。
3. **空快照保护**：当前账号读盘为空时改用内存 prevPlanets，绝不拿空数组去 tick 再写回（会把进度清空）。
- 探针 `docs/_probe_offline.mjs` 7/0：离线 2 小时后 采集(石头 2838→39614)、施工(队列 1→0)、产线(木头 0→490) 全部推进，且内存实例是推进后的新实例。
- **环境坑（重要）**：Node 里没 localStorage，state.js 默认 adapter 的 get 恒 null、set 静默失败 → 探针里「持久化+离线结算」整条链空转，会误判成「没推进」。自检脚本必须先 `S.setAdapter({get/set/del})` 注入内存 Map。另 `saveState()` 会把当前账号 lastSeen 刷成 now，测离线必须**先存档再改 lastSeen**。
- 化学实验室造价线上确认已是金属（curl 校验）；玩家看到旧值是**浏览器缓存**。已加 index.html 防缓存 meta（no-cache/no-store/must-revalidate）+ REVISION 提到 2（13.2）击穿缓存。
