# Astrix 飞船系统设计（v0.0.4）

> 设计者原始需求：「玩家可以自行组装蓝图，设计飞船，保证容量大于等于占地，同时根据引擎的强度和总物质的量计算速度，起飞消耗燃料。飞船外壳、武器和装甲的材料可以自选，材料属性影响这些装备的属性。」

## 二、材料如何影响装备

`js/core/shipyard.js` 的 `materialMul()` 是唯一入口。材料表的口径是「钢 = 基准」，所以：

| 倍率 | 公式 | 含义 |
|---|---|---|
| `structMul` | `max(0.3, strength / 35)` | 结构效率（钢 = 1.0，铝 ≈ 0.17，石墨烯更高） |
| `massMul` | `clamp(density / 3.3, 0.2, 8)` | 质量倍率（钢 = 1.0） |
| `heatMul` | `clamp(molarHeatCapacity / 0.13, 0.2, 6)` | 热容倍率 |

各部件怎么吃这三个倍率：

| 部件 | 结构 | 质量 | 耐热上限 |
|---|---|---|---|
| 外壳 | 强度 × `structMul` | 空重 × `massMul` | 熔点 × **0.40** |
| 引擎 | 推力 × `√structMul` | 质量 × `massMul` | 熔点 × **0.55** |
| 武器 | 伤害 × `(0.5 + 0.5·structMul)` | 质量 × `massMul` | 熔点 × **0.50** |
| 设施（装甲） | 加成 × `structMul` | 质量 × `massMul` | 熔点 × **0.45** |
| 设施（非装甲） | 不受材料影响 | 质量 × `massMul` | — |

全船**耐热上限取所有部件的最低值**——最弱的一环决定上限。

## 三、核心公式

### 容量与占地

```
占地合计 = Σ 各部件 footprint
合法条件 = 占地合计 ≤ 外壳容量  且  部件个数 ≤ 外壳槽位
```

### 航速

```
速度(m/s) = 300 × 总推力(kN) / 总质量(t) ^ 0.7
```

指数取 0.7 而不是 1，是为了让大船不至于慢到不可玩；推重比（kN/t）低于 2 会给「航速会很慢」的警告。

### 起飞燃料

```
Δv    = 2000 × (星球重力 / 9.0)          // 卫星容易起飞，辐射行星难
能量  = 0.5 × 质量(kg) × Δv² / 引擎平均效率
摩尔数 = 能量 / (该燃料游戏热值 × 1e5 J)
```

推论：**核燃料（铀 / 钚，热值高 7 个数量级）起飞几乎不耗料，化学燃料要几十万摩尔**。这是「铀钚 = 终局燃料」这条设计在飞船系统里的自然延伸。

### 温度与热平衡

```
发热  qGen = 引擎与武器的发热合计（停泊时按 15% 计，含生命维持）
辐射  qRad = 475 × 表面积 × (T/300)^4        // 斯特藩–玻尔兹曼
对流  qEnv = 14.3 × 表面积 × (T环境 − T)
表面积     = 5.3 × √容量
热容       = Σ(质量 × 热容倍率) × 0.02 × 3500 J/K   // 只取 2% 结构质量参与热平衡
```

- 环境温度按星球类型给（格拉西欧 225 K ~ 卡利多 330 K）
- **安全区间**：273–313 K，乘员仓每级把两端各放宽 4 K
- **致死区间**：253–333 K（同样被乘员仓放宽），超出后每秒按超出量比例掉人
- 温度超过**材料耐热上限**会烧穿船体（`hullIntegrity` 下降）

### 四项能量（飞船详情里展示）

```
内能 = 热容 × 温度
动能 = 0.5 × 质量(kg) × v²
势能 = 质量(kg) × 引力 × 高度        // 相对最近星球
```

## 四、蓝图评估

`evaluateBlueprint()` 输出：类型 / 型号 / 等级 / 强度 / 默认船名。

### 类型判定（按优先级）

| 条件 | 类型 |
|---|---|
| 有机库 | 母舰 |
| 总伤害 ≥ 150 | 战舰 |
| 载员 ≥ 60 | 殖民船 |
| 货舱 ≥ 500 m³ | 运输船 |
| 其余 | 探索船 |

### 强度与等级

```
强度 = 结构 × 0.8 + 伤害 × 0.08 + 速度/150 + 货舱/150 + 载员 × 0.25
等级 = 民用(<60) / 准军用(<120) / 军用(<240) / 主力舰(≥240)
```

### 默认船名

`<型号>级<类型>No.<同型序号>`，例如 **MKI级运输船No.1**。玩家可在飞船详情里改名。

### 校验（不通过就不给造）

1. 必须选外壳、至少 1 台引擎、最多 4 台
2. 占地 ≤ 容量（超出会写明超了多少 m³）
3. 部件个数 ≤ 槽位
4. **必须有乘员仓**（无人驾驶的船造不出来）
5. 所有部件的解锁科技都必须已研究（含 MK2 / MK3 节点）

警告（不拦，只提示）：推重比 < 2、乘员仓偏少、无武装。

## 五、飞船实例

存 `account.ships`，随存档持久化。每艘船带：

- 蓝图快照 + 实装属性快照（`stats`）
- `state`：所在星球、高度、速度、温度、三项能量、燃料 mol、船员数、船体完整度、是否在飞、是否幽灵船
- `inventory`：船上物品栏

心跳（`state.js` 的 `tick`）每秒推进一次：热平衡 → 船员损失 → 燃料消耗与加速 → 三项能量重算。船员归零后船变「幽灵船」，无法起飞。

## 六、v0.0.4 修掉的两个真 bug

| Bug | 现象 | 根因 | 修法 |
|---|---|---|---|
| 稳态温度迭代发散 | 新船出厂温度 **1.56 亿 K**，船员瞬间全灭、永远起飞不了 | `equilibriumTemp()` 的牛顿回代符号写反：`net(T) = qGen + qEnv − qRad`，其中 `qEnv` 与 `qRad` 都随 T 上升而增大，所以 `dnet/dT < 0`；代码里算出的 `dQdT` 是绝对值，却用了 `T -= net/dQdT`，等于把稳定性判据反过来 | 改为 `T += net/dQdT`，并给温度加 [3, 5000] K 兜底 |
| 默认蓝图 id 漏型号后缀 | 蓝图编辑器一打开就报「容量不足 30/0、部件槽位 2/0」 | `emptyBlueprint()` 写的是 `hullId: 'hull_s'`，而部件表里的真实 id 是 `hull_s_mk1`，`resolvePart` 查不到返回 `null`，容量与槽位全变 0 | 改为 `hull_s_mk1`，并在自检里加了「蓝图部件 id 必须存在于 `PART_BY_ID`」的断言 |
