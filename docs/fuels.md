# Astrix 燃料资源数据文档（研究稿 · 纯数据，非游戏代码）

> 本文件为「太空探索网页游戏 Astrix」新增「燃料资源」栏的数据底稿。
> 每种燃料两个核心参数均按**物质的量（摩尔）**度量：
> 1. **热值 heatValue**：每摩尔释放的能量（J/mol 或 kJ/mol），而非按质量。
> 2. **燃烧速率 burnRate**：单位时间内烧掉的摩尔数（mol/s），表征燃烧/反应的猛烈程度。

---

## 一、两个游戏刻度的定义与归一化公式

### 1. 游戏热值 `heatValue`（相对值，保留物理量级）
化学燃料按真实**摩尔燃烧焓**直接缩放，核燃料按真实**摩尔裂变能**缩放，统一除以系数 **100**：

```
heatValue = realHeat_kJ_per_mol / 100
```

- 化学燃料（碳、煤、氢、联氨、甲烷）的真实摩尔燃烧焓落在约 352–891 kJ/mol，
  除以 100 后游戏热值落在 **3.5 – 8.9** 的舒适区间，调参直观。
- 铀、钚为核裂变，真实摩尔裂变能约 **1.9×10¹⁰ kJ/mol**，除以 100 后约为 **1.9×10⁸**，
  如实反映核反应比化学反应高约 **7 个数量级**的能级跃迁——这正是核燃料作为「终局燃料」的物理本质。

> **标准煤的特殊处理（质量基准 → 摩尔当量）**：标准煤不是纯物质，其定义热值为
> **29307 kJ/kg**（= 7000 kcal/kg）。为与另外 6 种纯物质保持同一「每摩尔」基准，
> 将其折算为「碳当量摩尔」：1 mol 碳 ≈ 12.011 g = 0.012011 kg，故
> 标准煤碳当量摩尔热值 ≈ 29307 × 0.012011 ≈ **352 kJ/mol**（即把 1「游戏摩尔」煤
> 定义为「含 1 mol 碳当量的能量」）。原始质量基准 29307 kJ/kg 在表中一并保留。

### 2. 游戏燃烧速率 `burnRate`（mol/s 量级相对值，1× 燃烧强度下）
真实世界里没有现成的「mol/s 燃烧速率」通用数据，故采用**真实燃烧/反应猛烈程度排序**
（火焰传播速度、点燃难易、扩散限制等）作锚，压缩到游戏可玩区间：

```
burnRate = 设计相对值（mol/s @ 1× 燃烧强度），以甲烷 = 1.0 为基准锚定
```

- 气体燃料（氢、甲烷、联氨）火焰传播快、点燃易 → 速率高。
- 固体燃料（碳、煤）为表面/扩散控制，速率低。
- 核燃料（铀、钚）真实裂变消耗率极低（见第三节），为可玩性放大后给一个**低而可控**的速率，
  代表受控链式反应「细水长流」地释放能量。

### 3. 烧完时间（自洽约束）
在 **1× 燃烧强度**热机中，烧完 **1 mol** 该燃料所需时间恒满足：

```
burnTime1x(s) = 1 / burnRate        （装载量 = 1 mol，燃烧强度 = 1×）
总能量(1 mol) = heatValue × 1 mol
```

该约束对所有 7 种燃料（含核燃料）一律成立，保证数据自洽。

## 三、铀 / 钚（核燃料）的特殊处理与建议方案

**核心判断：核燃料不是「燃烧」，而是「受控链式裂变」。** 但其释放的是**每摩尔**能量，
与化学燃料的「每摩尔热值」在量纲上完全可比，因此推荐**直接并入同一 `heatValue` 刻度**：

1. **热值**：按真实摩尔裂变能如实计入（U-235 ≈ 200 MeV/裂变 → 1.93×10¹⁰ kJ/mol；
   Pu-239 ≈ 210 MeV/裂变 → 2.03×10¹⁰ kJ/mol），统一 ÷100。不做任何上限封顶，
   因为「核燃料能量密度比化学燃料高 7 个数量级」本身就是设计亮点（终局燃料）。
2. **燃烧速率（= 裂变吞吐率）**：真实工程消耗率极低——1 GW 热功率反应堆仅裂变
   约 **5×10⁻⁶ mol/s** 的 U-235（≈1 g/天·MWₜₕ）。若照此，1 mol 铀要烧 ~6 年，不可玩。
   故游戏将其**放大约 4000 倍**到 0.02 mol/s（钚 0.018），代表「受控、平稳、长时」的能量释放；
   烧完 1 mol 约需 50–56 秒（`burnTime1x`），远长于化学燃料。
3. **净效果**：1 mol 核燃料总能量是甲烷的约 **2×10⁷ 倍**，且以低速率缓慢释放，
   得到**极高总能量 + 高持续功率**的终局体验。所有自洽约束（含 `burnTime1x = 1/burnRate`）
   对核燃料同样成立。

**给策划的两条备选建议（如觉得真实量级破坏平衡）：**
- 方案 A（本文采用）：保留真实热值量级，仅对 `burnRate` 做可玩性放大 → 核燃料即「终极动力」。
- 方案 B：额外给核热机加「最大功率封顶」规则（如核引擎 `maxPower` 上限），在不改数据的前提下
  用引擎规则压住核燃料的压倒性功率，使其偏向「长续航」而非「爆发」。
